## Описание проекта

Программа представляет возможность бесконечной игры в змейку. Управление движением змейки происходит с помощью стрелок клавиатуры. Когда змейка съедает яблоко, она увеличивает свое тело на единицу. Жива змейка до тех пор, пока она не врежется в саму себя, и игра начинается с начала.

## Функциональные возможности

### Основной функционал
- 📐 Движение змейки через стрелки на клавиатуре 
- 🔍 Увеличение змейки после идеального попадания на яблоко
- ▶️ Смерть змейки, когда она натыкается сама на себя (начало новой игры)

### Дополнительный функционал
- 🎨 Нежно-розовый и фиолетовый интерфейс

## Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/valeriarrr/pink_snake_mimimi.git
cd pink_snake_mimimi
```

### 2. Создание и активация виртуального окружения
Windows:
```bash
python -m venv venv
venv\Scripts\activate
```
macOS/Linux:
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Запуск программы
```bash
python main.py
```
